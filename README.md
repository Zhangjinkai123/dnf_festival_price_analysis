## 📖 项目简介
**毒奶粉节日礼包物价记录档案与历史分析系统** 是一款专为《毒奶粉》玩家打造的高效物价追踪与跨年对比分析工具。

系统收录了 2025~2026 年耕耘、春节、夏日、金秋等四大节日礼包中 290+ 条核心可交易道具（称号、装扮、增幅券/强化券、宠物/宝珠、白金徽章等）的历史本期价、高价与低价档案，并提供玩家视角下的同类产物横向价格比对与多维分析。

## ✨ 页面与功能亮点

| 页面 / 模块 | 说明描述 |
| :--- | :--- |
| **🏠 首页 (`index.html`)** | **原始物价明细页面**。完整列出所有道具的年份、礼包类型、统计日期、本期价格、历史高/低价及历史区间涨幅。包含头部数据总量徽章与右上侧已筛选数量动态统计。 |
| **🏷️ 对比页 (`compare.html`)** | **跨年同类对比页面**。自动将不同年份的同类产物（如 2026 年与 2025 年的普通称号、+12 增幅券等）罗列对比，按**年份降序**排列，统计徽章与显示内容同一口径。 |
| **🔍 搜索框内容联想** | 支持输入关键字（如 `犬夜叉`、`称号`）自动弹出匹配下拉列表，支持鼠标与键盘 `↑/↓/Enter` 快速导航高亮选定。 |
| **💰 价格智能显示** | 千分位以细空格分隔（`10 888`）避免与小数点混淆；≥1亿自动显示为 `7.865 亿`，单位跟随数值；数据存储与导出仍统一为万金币。 |
| **🎛️ 自定义下拉组件** | 原生 select 展开弹窗无法用 CSS 美化，已用外观统一的自定义下拉替代，支持键盘 `↑/↓/Enter/Esc` 导航，筛选栏与管理弹窗全部生效。 |
| **⚙️ 产物映射表管理** | 允许玩家自主查看并修改同类产物的归类映射规则（支持多关键字逗号分隔），配置保存在 LocalStorage 并在对比页即时生效；官方新规则更新会自动并入本地配置。 |
| **💾 CSV / JSON 导出** | 支持一键导出全库物价数据为标准 UTF-8 CSV 或 JSON 文件，方便备份与分享。 |
| **🛡️ 部署访问模式** | 部署到服务器供他人访问时自动切换游客模式（隐藏管理入口，仅保留浏览与筛选）；本地 `file://` 或 `localhost` 打开为管理员完整模式。 |

## 🛠️ 技术架构与文件说明

* **多页面路由解耦**：原始物价明细（`index.html`）与跨年同类对比（`compare.html`）分离为独立页面，通过 Tab 页签平滑跳转切换。
* **数据与控制解耦**：数据（`data/`）、样式（`css/`）与逻辑（`js/`）彻底模块化分离。
* **智能数据加载**：优先异步 `fetch()` 加载标准 JSON 数据文件；同时支持本地 `file://` 协议无报错双击运行降级兼容。
* **全站资源本地化**：Tailwind CSS 预编译为本地静态文件（`css/tailwind.build.css`，构建命令 `npm run build:css`），字体使用系统字体栈，页面零外网请求——断网环境与 `file://` 双击打开均可完整运行。
* **部署访问模式**：部署到服务器供他人访问时自动切换游客模式（隐藏产物映射表/导出/新增等管理入口，仅保留浏览与筛选）；本地 `file://` 或 `localhost` 打开为管理员完整模式。配置见 `js/app.js` 顶部 `ACCESS_MODE`。
