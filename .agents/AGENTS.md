# Project Guidelines & Rules

- **功能可用性与自我验证原则**：对于后续所有的功能需求开发，必要前提是保持原功能的可用性。在向用户反馈结果之前，必须先在沙盒环境中自行完成验证。
- **物价数据录入标准规范**：当用户提供物价图片或文本要求导入/更新数据时，请严格参考 [DATA_IMPORT_GUIDE.md](../DATA_IMPORT_GUIDE.md)，同步写入 `data/price_data.json` 与 `js/data.js` 并按“万金币”统一换算。
- **产物映射规则更新规范**：导入新系列道具补全 `category_map.json` / `js/data.js` 映射后，若**新增**规则（新 label），浏览器会自动合并生效；若**修改了既有规则**的关键字，必须把 `js/app.js` 顶部 `MAP_KEY` 常量版本号 +1（如 `v2`→`v3`），否则保存过自定义映射的浏览器不会应用修改。
- **Tailwind CSS 构建规范**：页面工具类样式由本地预编译文件 `css/tailwind.build.css` 提供（自动生成，勿手改）。当 `index.html`、`compare.html` 或 `js/app.js` 中新增或修改了 Tailwind 工具类后，必须在项目根目录运行 `npm run build:css` 重新构建（首次需先 `npm install`），否则新类名不会生效。构建入口为 `src/input.css`；`css/style.css` 为手写自定义样式，修改后无需构建。站点运行本身零依赖，不需要 Node.js。
- **2026 金秋物价待更新（临时事项，完成后删除本条）**：2026-10-23 导入的 2026 金秋数据（统计日期 2026-09-11，34 条，森林乐团/森林流浪乐团系列）为**第一版快照**。礼包下架日期为 2026-12-10，下架前最后一周用户提供最终版物价图片后，需**替换更新**这批条目（修改统计日期与本期/高/低三项价格，**勿当作新快照重复追加**），备份与双端同步要求同 [DATA_IMPORT_GUIDE.md](../DATA_IMPORT_GUIDE.md)。
